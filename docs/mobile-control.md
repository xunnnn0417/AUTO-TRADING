# 手機控制

手機是操作入口；交易資料、試算表寫入、原有核對及平台操作均由電腦端執行。
不需要在電腦再輸入一次。手機輸入先同步為共用草稿，更新／填入時沿用原有套用流程。

## 開啟方式

1. 電腦完成方案、交易平台綁定與校準。
2. 「管理 → 手機連線」直接顯示固定入口設定，按「建立固定入口」。
   第一次請先安裝 Tailscale 並登入自己的帳號，再依提示允許入口。
3. 等待顯示固定手機網址。按「顯示 QR Code」用手機掃碼，再按配對碼旁的重整產生八位代碼。
   QR Code 在電腦本機產生，只含網址，不把配對碼交給其他服務。
4. 第一次啟用若無法建立安全連線，請等幾分鐘再試。
   [官方說明](https://tailscale.com/docs/features/tailscale-funnel#dns-propagation)指出公用 DNS 生效可能需約 10 分鐘；
   這是可能的首次等待時間，不代表每次重連都需要，也不是已量得的固定準備秒數。
5. 配對碼五分鐘內有效、僅能使用一次；五次錯誤後須重新產生。
   同一網址、同一瀏覽器重開會沿用配對；斷線或切回頁面自動重連，絕不重送交易。
   裝置授權保存 180 天，可由電腦移除；無痕模式、清除網站資料或不同瀏覽器不共用授權。
6. 「手機連線」設定視窗不會擋住手機操作；關閉它仍保留連線。
   執行交易功能沿用電腦的真實操作流程。
7. 手機首次開啟會顯示「加入手機桌面」引導。Android 支援時會叫出瀏覽器安裝確認；
   iPhone 在 Safari 按「分享 → 加入主畫面」。程式無法代替系統確認。
   建議設定固定入口後，先加入主畫面，再從圖示完成配對，避免瀏覽器與獨立視窗的資料分開。

## 不買網域的固定入口

1. 在電腦安裝官方 [Tailscale](https://tailscale.com/download/windows) 並登入自己的帳號。
2. 開啟「手機連線」，按「建立固定入口」。
3. 若出現「允許固定入口」，按下後在官方頁面完成首次授權；不自動略過同意。
4. 取得固定 `https://…ts.net:8443` 網址後，手機掃碼並配對一次。
   同一電腦、同一 Tailscale 網域及手機網站資料保留時，重開程式會恢復同一入口；
   配對授權有效 180 天。電腦仍需開機、登入及保持連線。

依 [Funnel 官方說明](https://tailscale.com/docs/features/tailscale-funnel)，手機可直接用公開 HTTPS 網址，
不需安裝 Tailscale。程式僅啟動自己的前景轉送程序，不安裝常駐服務、不清除其他轉送設定；
停止手機連線或關閉程式會結束此程序。更換電腦／網域或清除手機網站資料後可能需要重新配對。
此入口須完成帳號、登入及外網實機驗證後，才能稱為可用。

QR 顯示／收合會重新配合內容縮放視窗，裝置清單維持固定高度；較矮螢幕可捲動。
配對碼旁的 ↻ 可重新產生一次性代碼，並顯示剩餘時間；過期、已使用或錯誤次數過多會分開提示。

介面不再提供臨時網址、手動填固定網址或電腦預覽入口；既有配對資料保留。
Tailscale 登入完成後可以關閉其視窗，但需讓服務保持背景執行。
「停止手機連線」會中斷手機遠端連線，不會平倉或撤回已送出的操作；此時也不會繼續接收手機指令。
移除手機按鈕顯示在已選裝置列內，再次點選同一裝置可取消選取；視窗高度不隨選取變動。
關閉設定視窗使用右上角 ×。手機消息採即將發生／已公布分頁，點消息整列可展開內容；
預期、前值及公布值依來源分欄顯示。倒數使用獨立提示格，每秒更新，旁列台北時間的 AM／PM 公布時間，跨日以累計小時顯示；不增加消息抓取頻率。交易操作結果只留在交易頁。
手機「消息 → 鈴鐺」可啟用背景通知，需本人允許系統權限；不會自動跳出權限要求。
通知包含新收到的突發重大消息、已排程事件公布前十分鐘及公布當下；不通知行情回顧。
同一時間、同一類提醒會合併顯示多則名稱；各則仍分別保留去重及重試紀錄，不合併不同手機或公布前／公布當下的提醒。公布當下只提醒時間已到。
首次在十分鐘內開啟時，提醒顯示實際剩餘分鐘；不補發過期排程。公布當下只提醒時間已到，
來源提供結果後才在消息頁顯示實際內容，不把排程當成數據已取得。
iPhone／iPad 需 iOS／iPadOS 16.4 以上，先加入主畫面並從圖示開啟，再按「啟用通知」。
可用「測試通知」確認這支手機收得到；每次測試間隔十秒，按鈕顯示倒數，重複點擊不會無提示地被忽略。「關閉通知」或在電腦移除裝置後會停止發送。
電腦程式與手機連線須保持開啟。手機鎖定或關閉網頁仍可由系統接收，送達時間受手機網路、
省電／專注模式及系統通知設定影響，不能保證即時。實際手機背景送達仍需使用者驗收。
推播由瀏覽器的 Apple／Google／Mozilla 服務轉送，內容使用標準 Web Push 加密；
訂閱及私鑰只保留在本機，不上傳 GitHub。只發消息，點通知只開啟消息頁，不能執行交易。
通知入列後立即背景派送，不等待下一輪排程檢查；不增加新聞抓取頻率。
本機 diagnostics/mobile-notifications.json 記錄最近一百筆送出狀態、排隊與完成耗時；
完成耗時包含背景工作及回到介面的時間，服務接受不代表手機已顯示。
不設定路由器、不開放防火牆連接埠，不公開檔案或遠端桌面。
`127.0.0.1` 只代表本機，不能把本機預覽網址直接交給另一台手機使用。
HTTPS／配對／WebSocket 已用隔離頁實際通過外網通道驗證；實際手機、加入主畫面與交易流程仍須使用者驗收。

連線啟動、接通及失敗原因留在本機 `diagnostics/mobile-connection.json`，最多保留 20 筆；
不記錄手機配對碼、Cookie、完整網址或本機路徑，不上傳。連線失敗不會重送交易。

Windows 使用原生 Schannel 加密後端，載入時隔離不相容的 OpenSSL 插件並恢復原搜尋路徑。
沿用系統憑證核對，不關閉 HTTPS 驗證，也不修改共用 Python 環境。

## 範圍與資料同步

- 首頁：已設定方案、階段、方向、預期 SL、餘額、每日盈虧、更新、填入兩邊、手數與帳號進度。
- 「其他交易操作」預設收起：單邊填入、查看止盈止損、同步、進場點位及交易選項。
- 消息共用電腦已取得的事件，不另建立一套抓取排程。
- 手機的「交易操作／消息」分頁分開；即將發生按最近時間排序、限制近期排程，已公布按最新在前。
- 帳號進度由電腦同一個進度尺繪圖，經配對後取得，不另實作計算與位置規則。
- 一般成功更新只顯示短訊息；風險確認及錯誤仍需處理。行情回顧不顯示於事件清單，也不通知。
- 來源提供公布值、預期、前值或 RSS 內容時顯示該筆內容；來源沒有結果時明示缺資料，不自行推算。
- 不提供試算表設定、校準、視窗綁定、檔案存取、終端機或任意滑鼠／鍵盤命令。
- 手機修改後由電腦回報最新草稿及已套用值；兩者分開顯示。
- 執行中／電腦鎖定／有未完成確認時，其他交易輸入不可操作。
- 交易參數在接收後又有改動，本次操作會拒絕；不悄悄使用另一份數值。
- 原有交易確認會傳回手機供選擇，並不因遠端而自動略過；無法呈現的輸入視窗會明示需電腦處理。
- 完成、未執行、失敗、結果待核對分開顯示；成交成功必須有原流程的確認結果。

## 連線與安全邊界

- 使用既有 PySide6 的 Qt Network／WebSockets，不新增下載執行的套件。
- 僅監聽 loopback；外網需明確設定 HTTPS 轉送，不可直接公開明文連接埠。
- 網頁、Origin 與 Host 僅接受指定站點；配對授權使用 HttpOnly／SameSite Cookie，
  外網加 Secure。JavaScript 不持有裝置憑證，不儲存於 localStorage。
- 裝置只保存高隨機憑證的雜湊；配對碼及 Cookie 不寫操作日誌或發布包。
- 操作 ID 在本機獨立資料庫保存；同 ID 不執行第二次，重啟後未完成操作標示未知，永不自動重送。
- 主動斷線不代表已停止執行；重新連線先查結果。停止按鈕沿用原有緊急停止，不會自行平倉。
- 私人裝置授權與操作結果留在電腦資料目錄，不放入方案、不上傳 GitHub。

## 工程驗證

既有 unittest 流程：

```text
python -m unittest discover -s tests -p test_mobile_remote.py -v
python -m unittest discover -s tests -p "test_*.py" -q
python -m compileall -q trading_helper
```

使用隔離暫存設定、loopback 測試連線與模擬操作；不得把測試訊息當作實際成交驗收。
